Embedded Login enables flexible, custom authentication experiences directly within your application. Here are the four core use cases where developers leverage embedded authentication flows to build secure, native experiences.

<CardGroup cols={2}>
<Card title="Login" icon="right-to-bracket" href="/docs/authenticate/login/embedded-login/use-cases/login">
  Authenticate existing users directly in your app without redirects using ROPG, passwordless OTP, or native passkeys.
</Card>

<Card title="Sign-up" icon="user-plus" href="/docs/authenticate/login/embedded-login/use-cases/sign-up">
  Create new user accounts with custom onboarding, progressive profiling, and conditional flows.
</Card>

<Card title="Step-up Authentication" icon="shield-check" href="/docs/authenticate/login/embedded-login/use-cases/step-up">
  Re-verify user identity before sensitive operations using MFA challenges within your app.
</Card>

<Card title="Enrollment" icon="lock" href="/docs/authenticate/login/embedded-login/use-cases/enrollment">
  Let users add credentials, factors, and connected accounts during onboarding or from a settings page without leaving your app.
</Card>
</CardGroup>
