Embedded Login lets you build a fully custom authentication experience within your application. Users authenticate directly in your UI without being redirected to an external login page, giving you complete control over the look, feel, and flow of the login process.

## When to use Embedded Login

Choose Embedded Login when you need:

* Complete control over UI/UX to match your application's exact design system
* Users to remain in your application throughout authentication without redirects
* Custom authentication flows such as progressive profiling, conditional logic, or multi-step challenges
* Native mobile app authentication without browser redirects
* In-app authentication for sensitive operations (checkout, payments, account changes)
* Authentication integrated into conversational or non-traditional interfaces (AI agents, chatbots)

## Capabilities

Embedded Login supports a comprehensive set of authentication patterns:

**Identity providers:**
* Database connections (username/password, passwordless)
* Email and SMS passwordless authentication
* Native social login (Google, Apple, Facebook) via platform SDKs without opening a browser
* Native passkey enrollment on iOS and Android

**Advanced authentication:**
* <Tooltip tip="Multi-factor authentication (MFA): User authentication process that uses a factor in addition to username and password such as a code via SMS." cta="View Glossary" href="/docs/glossary?term=Multi-factor+authentication">Multi-factor authentication (MFA)</Tooltip> with multiple factors and ad-hoc challenges
* Step-up authentication for sensitive transactions
* Demonstrating Proof of Possession (DPoP) for token binding

**Session and token management:**
* Customizable token lifetimes and refresh strategies
* Session persistence and resumption

## Comparing Embedded Login and Universal Login

Both approaches are fully supported. Choose based on your application's specific requirements:

* **Embedded Login** — Full UX control, redirect-free, custom flows. Requires more development effort but provides the most flexibility.
* **Universal Login** — Faster to implement, automatic security updates, simple configuration. Best for standard use cases and multi-domain SSO.

To see a detailed comparison, read [Universal Login vs. Embedded Login](/docs/authenticate/login/universal-vs-embedded-login).
